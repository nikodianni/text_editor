editor.app module¶

Hlavní modul aplikace textového editoru.

Definuje třídu EditorApp, která inicializuje hlavní okno, sestavuje horní menu, zajišťuje klávesové zkratky a spravuje operace se soubory (otevření, uložení, ukončení).

editor.tab module¶

Modul pro správu jednotlivých záložek textového editoru.

Obsahuje třídu EditorTab, která sdružuje textovou oblast, číslování řádků, správu témat (světlý/tmavý režim) a automatické zvýrazňování syntaxe pro Python.
